# Library-Management-System
A Library Management System developed in C to efficiently manage books, members, and borrowing/return operations.

A C#-based Library Management System developed to simplify library operations by managing books, members, and issue/return records efficiently.

📂 Project Structure

```text
LibraryManagement/
LibraryManagementUnitTests/
LibraryManagement.zip
```

✨ Features

- Add, update, delete, and view book records
- Manage library member information
- Issue and return books
- Unit-tested application for better reliability

🛠️ Technologies Used

- C#
- .NET Framework
- Visual Studio
- Unit Testing

🚀 Getting Started

Prerequisites

- .NET SDK
- Visual Studio or Visual Studio Code

Installation

```bash
git clone https://github.com/YourUsername/LibraryManagement.git
```

Build the project

```bash
dotnet build
```

Run the application

```bash
dotnet run --project LibraryManagement
```

Run Tests

```bash
dotnet test LibraryManagementUnitTests
```
